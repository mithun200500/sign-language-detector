# Sign Language Detector ✋🤟

A real-time sign language recognition system built with **MediaPipe**, **OpenCV**, and **scikit-learn**. It tracks your hand through a webcam, extracts landmark coordinates, and classifies the sign being shown using a trained Random Forest model.

> ⚠️ Replace this section with a GIF or screenshot of the app running once you've recorded one — it makes a huge difference for anyone browsing your repo.

## 🚀 Features
- Real-time hand tracking via MediaPipe (21 landmark points per hand)
- Custom data collection pipeline — train it on any signs you want (ASL alphabet, custom gestures, etc.)
- Random Forest classifier with confidence-threshold filtering to avoid false predictions
- Fully local — no cloud services, no paid APIs, runs entirely on your machine

## 🛠️ Tech Stack
- Python 3.9+
- OpenCV (video capture, display)
- MediaPipe (hand landmark detection)
- scikit-learn (Random Forest classifier)
- pandas / numpy (data handling)

## ⚙️ Setup

1. Clone the repo:
   ```bash
   git clone https://github.com/<your-username>/sign-language-detector.git
   cd sign-language-detector
   ```

2. Create a virtual environment (recommended):
   ```bash
   python -m venv venv
   venv\Scripts\activate      # Windows
   source venv/bin/activate   # macOS/Linux
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## ▶️ Usage

### Step 1 — Collect training data
```bash
python collect_data.py
```
- Enter a label (e.g. `A`, `B`, `Hello`, `ThankYou`)
- Press `s` to start capturing, `p` to pause, `n` to switch to a new label, `q` to quit
- Aim for 100–200+ samples per sign, varying hand angle/position slightly

### Step 2 — Train the model
```bash
python train_model.py
```
This trains a Random Forest classifier on your collected data and saves it as `model.pkl`, printing accuracy and a classification report.

### Step 3 — Run the live detector
```bash
python app.py
```
Show a trained sign to your webcam — the predicted label and confidence appear on screen. Press `q` to quit.

## 📈 Possible Improvements
- Support two-hand signs (currently limited to one hand at a time)

- Swap Random Forest for an LSTM/GRU to capture motion-based signs (not just static poses)
- Build a Flutter or Streamlit front-end for a more polished demo
- Add text-to-speech so recognized signs are spoken aloud
